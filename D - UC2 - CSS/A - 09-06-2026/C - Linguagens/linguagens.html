Linguagens de Programação

Linguagens de programação são conjuntos de regras e símbolos usados para instruir o computador a executar tarefas. Elas variam conforme a área de atuação, indo desde o desenvolvimento web até a inteligência artificia

Principais linguagens de programação utilizadas

Logotipo Linguagem Sobre Ano de criação Criador
1. Python Famosa pela sintaxe limpa e legibilidade. É a principal linguagem para Inteligência Artificial, ciência de dados, machine learning e automações. 20 de fevereiro de 1991 Guido van Rossum
2. JavaScript Essencial para a web moderna. Roda diretamente nos navegadores e é usada para criar a interatividade de quase todos os sites. 4 de dezembro de 1995 Brendan Eich
3. Java Utilizada em sistemas empresariais de grande porte e no desenvolvimento de aplicativos Android. 23 de maio de 1995 James Gosling
4. C# (C-Sharp) Linguagem muito versátil da Microsoft. É a escolha padrão para a criação de jogos na engine Unity e para softwares empresariais. 26 de julho de 2000 Anders Hejlsberg
5. TypeScript Uma evolução do JavaScript criada pela Microsoft, muito utilizada hoje para adicionar mais segurança e organização a grandes projetos web. 1 de outubro de 2012 Anders Hejlsberg
6. Rust Focada em desempenho e alta segurança, tem ganhado o coração da comunidade de desenvolvedores para criar sistemas complexos e rápidos. 15 de maio de 2015 Graydon Hoare
