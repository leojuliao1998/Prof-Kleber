Seção 1 — O que é display: flex

Sem Flexbox, blocos (div) ficam empilhados verticalmente. Com display: flex, os filhos diretos ficam lado a lado no eixo principal.

Seção 7 — order e align-self

order e align-self são aplicados nos itens flex, permitindo controlar ordem e alinhamento individual.

order — mudando a ordem visual

No HTML a ordem é 1, 2, 3 — mas o CSS altera a exibição:

1 (order: 0)
2 (order: -1)
3 (order: 2)

align-self — alinhamento individual no eixo cruzado

Padrão
